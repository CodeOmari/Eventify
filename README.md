# Eventify
An Event Management System built with Django


# Features
This project contains the following features: Dashboard page(Coming soon), Discover events page, 
User management section for event organizers only, Create events page, Search events section and Book event tickets and Receive Email with ticket details.

# Tech Stack
The following languages are used in this project: Bootstrap, CSS, HTML & Python(Django)
